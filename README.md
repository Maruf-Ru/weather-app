# Weather App

Shohor-er naam likhe abhawa dekhar ekta choto web app.

**Live link:** https://maruf-ru.github.io/weather-app/

## Features

- Shohor-er naam diye search (button ba Enter key)
- Temperature ar batash-er gati
- Abhawa onujayi emoji
- Shohor na pele ba network-e somossha hole error message

## Technology

- HTML
- JavaScript (fetch, async/await)
- [Open-Meteo API](https://open-meteo.com/)
